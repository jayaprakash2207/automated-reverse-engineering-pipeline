# Response Style Feedback

Keep answers short and direct. User repeatedly says "just say" to signal he wants a one-line or one-table answer, not a paragraph.

**Why:** User is efficient and focused. Long explanations slow him down and he will re-ask with "just say" to trim the answer.
**How to apply:** Default to the shortest accurate answer. Only expand if user says "explain it" or asks a how/why question. Never repeat what was just said. No trailing summaries.
